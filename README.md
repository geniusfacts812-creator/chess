# ♞ Шахматы

Браузерные шахматы на чистом HTML/CSS/JS — без библиотек и сборки. Один файл `index.html`.

## Возможности
- Игра против компьютера (4 уровня сложности) или вдвоём на одном экране
- Полные правила: рокировка, взятие на проходе, шах, мат, пат
- Превращение пешки с выбором фигуры (ферзь, ладья, слон, конь)
- Шахматные часы (от 1 до 30 минут)
- Плавные анимации ходов и рокировки, список ходов
- Меню «Обучение» с описанием фигур по возрастанию ценности
- Темы доски и свои цвета
- Работает на телефоне и компьютере, можно установить как приложение (PWA) и играть офлайн

## Запуск
Откройте `index.html` в браузере — больше ничего не нужно.
Для режима PWA (установка и офлайн) страницу нужно открывать по `https://`, например через GitHub Pages.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки:
   ```bash
   git init
   git add .
   git commit -m "Шахматы"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`, **Save**.
3. Через минуту игра будет доступна по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Яндекс Игры
```bash
python3 tools/make_yandex.py
```
Скрипт создаст `dist/chess-yandex-games.zip` — этот архив загружается в Консоль разработчика
(вкладка «Черновик»). В него добавляется SDK Яндекс Игр, а файлы PWA убираются.

## Google Play
Игру можно упаковать в Android-приложение через [Capacitor](https://capacitorjs.com/) или
[Bubblewrap/PWABuilder](https://www.pwabuilder.com/) (для этого страница должна быть опубликована по HTTPS, например на GitHub Pages).

## Структура
| Файл | Назначение |
|---|---|
| `index.html` | вся игра |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | установка как приложение и офлайн-режим |
| `tools/make_yandex.py` | сборка архива для Яндекс Игр |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |
